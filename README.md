# ESP32 MUSE Gadget 🤖

This project consists of <ins>a custom designed PCB</ins> that consists of:  

| **1x** | SeedStudio ESP32-S3 Board     | [Seedstudio](https://www.seeedstudio.com/XIAO-ESP32S3-p-5627.html) |  
|--------|-------------------------------|---------|  
| **1x** | active Buzzer                 |  myself |  
| **1x** | SH1106 1.3 Inch OLED-Display  |  myself |  
| **4x** | LED-Diode                     |  myself |  
| **4x** | 220 Ohm Resistors             |  myself |
